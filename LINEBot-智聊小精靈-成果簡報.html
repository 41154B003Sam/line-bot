智聊小精靈 (Gemini Smart Bot) 改善版
基於 Google Gemini 模型之繁體中文生活對話助理 — 專題名稱、受眾與痛點解析
📌 專題名稱與命名意涵

官方專題名稱：智聊小精靈 (Gemini Smart Bot)
命名意涵：以「智慧聊聊」為概念，化身為常駐在每位使用者 LINE 聊天室裡的輕巧小精靈。免去額外下載獨立 App 或前往網頁登入的麻煩，打開 LINE 即可 24/7 隨問隨答。

👥 使用對象 (Target Audience)
  • LINE 高頻度日常使用者：上班族、學生、家庭日常等通訊族群。
  • 生活靈感與文案速查者：想隨手查詢旅遊景點、美食餐廳或潤飾信件的人。
  • 追求極簡無廣告者：厭倦複雜介面，偏好一對一直接問答的使用者。
🎯 想解決的核心問題 (Problem Solved)
  • 痛點一：跨 App 查詢之操作負擔
    傳統使用生成式 AI 需開啟瀏覽器或特製工具；本 Bot 讓 AI 直接融入日常生活聊天室。
  • 痛點二：傳統 Bot 死板且缺乏實用性
    突破傳統 Echo Bot 鸚鵡學舌或關鍵字精確匹配的生硬體驗，賦予真正的自然語言語意推理。
  • 痛點三：手機端排版長度混亂
    解決一般 AI 容易輸出過長字串或帶有粗體星號（**）的問題，專注於手機閱讀的最佳化收斂。

核心功能特色與真實對話展示
繁中語意問答、長度邊界收斂、Markdown 清洗與智慧防呆引導
⚡ 核心功能：繁中語意問答與排版收斂
  • Gemini Flash 驅動：官方 SDK 整合，注入親切幽默繁中人設。
  • 四重模型自動備援：flash-latest ➜ 3.8-flash ➜ 3.5-flash ➜ flash-lite，抵禦 503 尖峰限流。
  • 長度邊界安全截斷：嚴控 250~450 字（上限 500 字），並在句尾標點自然收尾。
  • 排版星號清洗：移除 ** 粗體星號，改採親切 Emoji 與換行呈現。
  • 改善版防呆升級：空白訊息提醒、模糊字主動引導、非文字格式提示。

AI 協作開發與關鍵除錯修正經驗

🛠️ 使用的 AI 工具

Google Antigravity AI Agent、Google Gemini 3.8 Flash、Git / GitHub CLI、Edge Headless PDF 渲染引擎。

💬 代表性指令 (Prompt)
「請以 Python 3.12 與 LINE Messaging API v3 為架構，串接 Google Gemini API。
要求：
1. 設計四重模型自動降級佇列（gemini-flash-latest -> 3.8-flash -> 3.5-flash -> flash-lite）。
2. 控制輸出為台灣繁體中文，字數 250~450 字，移除 Markdown 雙星號。
3. 實作標點符號安全句尾截斷演算法，確保 500 字內不中斷半句。」
🔍 檢查與修正 AI 產出的真實經驗
【發現問題】
在 Windows 繁體中文環境測試時，AI 產出的原始程式碼直接呼叫 print() 列印包含 Emoji 的 Gemini AI 回覆，導致 Windows 終端機 cp950 / Big5 編碼直接噴出致命錯誤：
UnicodeEncodeError: 'cp950' codec can't encode character，造成後端伺服器崩潰中斷！

【檢查與手動修正】
經由檢視伺服器日誌發現是平台編碼衝突，我要求 AI 在 app.py 最前緣強制將底層標準輸出重定向為 UTF-8：
sys.stdout.reconfigure(encoding="utf-8", errors="replace")
並同步為語音、位置、影片新增專屬事件攔截器，徹底消除非預期崩潰。

🌱 心得與改善前後差異
• 前後差異：第一版遇到非文字格式無反應且模糊字易浪費 Token；改善版達成 100% 格式反饋、空白防呆引導、並提供離線「說明」指令。
• 核心心得：AI agent 能極速加速代碼產出，但唯有開發者深入理解邊界條件與平台相容性，才能打磨出健全穩定的商業級作品。
⚠️ 已知限制與下一步藍圖
1. 無對話記憶 (Stateless) ➜ 下一步引入 Redis 儲存最近 3~5 輪對話脈絡。
2. 本地主機依賴 ➜ 下一步將 Docker 容器化部署至 Google Cloud Run 雲端。
3. 無圖文選單 ➜ 下一步在 LINE 後台建立六宮格 Rich Menu 快捷按鈕。
